
  What exists today is an offline, stressor-driven pipeline through collection → features → Isolation Forest → causal graphs. The
  stated end goal (background monitoring + RAG explanation to the user) is not implemented (ragExplainer.py / daemon missing).

  What can work

  • Collection via sudo python3 parentProcess.py <stressor> with probes.bt, extractors, and wakeupTracker.bt
  • featureExtractor.py → anomalyDetection.py → analyzeCausalGraphs.py as a batch chain, if all expected data/* inputs exist
